# Portfólio — Pedro Lucas

Site de portfólio pessoal desenvolvido com Next.js, React e TypeScript.

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP e Three.js (animações)

## Rodar localmente

```bash
npm install
npm run dev
```

O site fica disponível em `http://localhost:3000`.
